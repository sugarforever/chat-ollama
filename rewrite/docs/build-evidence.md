# Runtime build evidence

- Pi 1.4.0 supplies durable submission admission, task checkpoints, SQLite storage, restart recovery, committed watches, abort, and safe/unsafe tool replay policy. The app still owns authentication, configuration, application HTTP/SSE contracts, knowledge ingestion/search, MCP connectivity, and UI.
- Real local OpenAI-compatible HTTP fixture and child processes prove an admitted model request resumes after SIGKILL without another user input; completed work is not rerun after a later reopen. Separate conversation files run concurrently. Browser observer detachment does not cancel work. No external API credentials were used.
- Actual friction: pnpm initially discovered an ancestor workspace; stopped that install and added a standalone boundary. Main-branch README watch APIs differ from pinned 1.4.0. Type checking caught the mismatch and an explicit watch test reproduced it. Pi IDs are numeric brands and are converted to strings at the public boundary. Pi's built-in OpenAI provider uses Responses; a custom provider selects Chat Completions for compatible endpoints and sets model and provider base URLs.
- Runtime target is Node 24.22.2 LTS. Host default Node 26.8.1 was not used for final verification. SQLite emits Node's experimental SQLite warning in child stderr; no process or storage errors are suppressed.

- Task 2 adds actual built SvelteKit HTTP routes, catalogue-first recoverable creation, durable identical-request retry/conflict checking from pi's persisted user entry, busy rejection, idempotent Stop, and bounded full-snapshot SSE. Tests SIGKILL the HTTP child after admission, retry the original receipt after restart, and compare completed transcript after another restart. Unknown and malformed IDs do not create session files.
- Snapshot projection uses pi 1.4.0's actual submission outcomes and task abort marks, not the nonexistent runFailure field. Real streaming and error HTTP fixtures prove committed partial text, cancelling, persisted failure after reopen, and omission of provider secret errors. A pinned-shape projection fixture covers running tools and interrupted-result uncertainty; actual MCP execution/replay belongs to Task 4.
- A 10,000-update slow-reader test observes only the newest pending snapshot and verifies watcher removal on reader cancel and request abort. Actual HTTP disconnect/reconnect proves work finishes after detachment and Last-Event-ID cannot suppress the final resnapshot. An initial throwing listener regression failed with four invocations before its removal was fixed.
- Node 24 full verification for Task 2: 5 test files / 15 tests pass, svelte-check reports zero errors and warnings, and production build succeeds. Explicit startup esbuild --tsconfig removes its ancestor-config warning. Vite still discovers legacy ancestor Nuxt tsconfig while loading/building; SvelteKit under Vitest reports an overridden base; adapter-node's separate Rollup pass warns that node:sqlite is external. Built HTTP tests execute that import successfully. Warnings are not suppressed and no legacy configuration is changed.
